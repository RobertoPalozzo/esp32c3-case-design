# ESP32C3 Case Design

A documentation website for the design and 3D printing journey of a protective case for the ESP32-C3 Zero microcontroller board.

## Project Overview

This project was completed as part of **Assessment Task 3** for the **Certificate III in Information Technology** at **Kangan Institute – Broadmeadows VIC**.

The website documents the full design process, from the first prototype to the final product, including problems encountered, improvements made, and test results.

## Website Pages

| Page | Description |
|------|-------------|
| `index.html` | Home page – project introduction and purpose |
| `prototype1.html` | Prototype 1 – first design, photos, pros, cons and planned improvements |
| `prototype2.html` | Prototype 2 – 3D design images, improvements from Prototype 1 |
| `final.html` | Final Design – features, comparison table across all prototypes |
| `contact.html` | Contact – author info and feedback form |

## Technology Used

- HTML5 / CSS3
- Google Fonts (Inter)
- 3D modelling: Tinkercad
- 3D printer: BambuLab A1 (PLA filament)
- IDE: Visual Studio Code
- Version control: Git / GitHub
